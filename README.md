# Haro-Compose-Carrot

# 컴포넌트 구성(MainPage)

## AppBar

> 앱 상단에 위치하는 바

- RegionDropdownMenu : 지역을 선택할 수 있는 드롭다운 메뉴

- SearchButton : 상품명을 검색할 수 있는 버튼

- ShowMenuButton : 메뉴를 보여주거나, 숨길 수 있는 버튼

- ShowAlertButton : 알림을 보여주거나, 숨길 수 있는 버튼

## ConditionBar

> 검색의 옵션을 정할 수 있는 바

- ResetButton : 검색의 옵션을 초기화할 수 있는 버튼 

- RangeDropdownMenu : 정해진 범위의 지역에서 구체적으로 선택할 수 있는 드롭다운 메뉴

- PriceDropdownMenu : 가격의 범위를 선택할 수 있는 드롭다운 메뉴

- CategoryDropdownMenu : 카테고리를 선택할 수 있는 드롭다운 메뉴

- SearchDropdownMenu : 정확도, 최신순 등으로 검색 옵션을 선택할 수 있는 드롭다운 메뉴

## GoodsCard

> 상품의 정보를 나타내는 상품 카드

- GoodsImage : 사용자가 올린 상품 이미지

- TitleText : 사용자가 입력한 제목을 나타내는 텍스트

- DistanceText : 주변 거리와 위치를 나타내는 텍스트

- CreationTimeText : 작성자가 글을 올린 후에 얼마나 지났는지를 보여주는 텍스트

- ReservationText : 다른 고객이 예약중이라면 예약중이라는 것을 나타내는 텍스트

- PriceText : 작성자가 지정한 금액을 보여주는 텍스트

- LikeInfo : 좋아요가 눌린 수와 아이콘을 보여주는 정보

- ChatInfo : 채팅이 얼마나 이루어졌는가를 보여주는 정보

## AddButton
